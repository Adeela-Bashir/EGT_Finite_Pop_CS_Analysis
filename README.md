# Finite Population EGT for Cyber Security: Asymmetric AI Access

MATLAB implementation analyzing stochastic dynamics in finite populations of cyber attackers/defenders with differential AI tool access.

## 🎯 Overview

Models stochastic dynamics, bounded rationality, and strategic imitation under asymmetric AI capabilities.
